# Live Feed

Live Feed — это боковая панель реального времени, которая отображает сообщения логов и дампы переменных по мере их появления в вашем приложении. Она слушает Server-Sent Events (SSE) от бэкенда и показывает их мгновенно, без перезагрузки страницы.

![Панель Live Feed с записями логов и дампов](/images/features/live-feed.png)

## Открытие Live Feed

Нажмите **иконку терминала** в верхней панели, чтобы открыть панель Live Feed с правой стороны экрана. Бейдж на иконке показывает количество непрочитанных событий.

Панель можно закрыть, нажав кнопку **X** или кликнув за её пределами.

## Типы событий

Live Feed отображает два типа событий реального времени:

### События логов

Сообщения логов транслируются через прокси `LoggerDecorator` каждый раз, когда ваше приложение записывает сообщение через PSR-3 Logger. Каждая запись лога показывает:

- **Метка времени** — когда лог был получен
- **Чип уровня** — цветовая индикация важности (ERROR = красный, WARNING = жёлтый, INFO = зелёный, DEBUG = серый, CRITICAL = тёмно-красный, NOTICE = синий)
- **Сообщение** — текст сообщения лога
- **Контекст** — раскрываемое JSON-дерево с данными контекста лога (нажмите, чтобы развернуть)

### События дампов

Дампы переменных транслируются через `VarDumperHandler` каждый раз, когда ваше приложение делает дамп переменной. Каждая запись дампа показывает:

- **Метка времени** — когда дамп был получен
- **Чип DUMP** — в предупреждающем/оранжевом цвете
- **Строка источника** — кликабельная ссылка на путь к файлу (открывается в настроенном редакторе)
- **Дерево переменной** — раскрываемый просмотр переменной с аннотациями типов

## Как это работает

Панель всегда подключается к `/debug/api/event-stream` и слушает:

| Тип SSE-события | Источник | Описание |
|-----------------|----------|----------|
| `live-log` | `LoggerDecorator` | Сообщение лога PSR-3 с уровнем, сообщением и контекстом |
| `live-dump` | `VarDumperHandler` | Дамп переменной со значением и расположением исходного файла |

События хранятся в памяти (до 500 записей) и отображаются в обратном хронологическом порядке (сначала новые).

## Генерация тестовых событий

Используйте CLI-команду broadcast для отправки тестовых событий:

```bash
# From your application directory
php yii dev:broadcast -m "Test log message"
```

Она отправляет и сообщение лога, и дамп переменной всем подключённым SSE-слушателям.

## Очистка событий

Нажмите **иконку корзины** в заголовке панели, чтобы очистить все накопленные события. Счётчик непрочитанных на иконке верхней панели сбрасывается автоматически при открытии панели.

## Требования

- Для потоковой передачи событий в реальном времени должно быть установлено PHP-расширение **sockets**
- Ваше приложение должно использовать прокси `LoggerDecorator` и/или `VarDumperHandler` (настраиваются адаптерами автоматически)
